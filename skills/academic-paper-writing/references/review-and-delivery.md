# Review and Delivery

Use this reference for a requested manuscript review, submission check, or PDF
delivery. Scale coverage to the request: a local revision needs focused checks;
a final audit covers the requested main paper and supplement.

## Review the intended visible version

Identify the source version and output roots being reviewed. Read the actual
generated PDFs and use source files to locate issues. If the request concerns final
visible content, do not report commented-out passages or hidden historical drafts
as current paper errors.

When the manuscript changes during review, revisit affected findings rather than
carrying an old issue list forward unchanged. If compilation or rendered-page
inspection is unavailable, state which checks remain unverified.

## Check language and visible content

Look for definite spelling errors, missing or joined words, incomplete sentences,
incorrect grammar or punctuation, and inconsistent parallel constructions.
Remove unintended duplicate headings and redundant text when editing is authorized.
Preserve accurate, readable prose instead of rewriting it to match a preferred style.

Check rendered formulas, indices, summation limits, and symbol explanations.
A syntactically valid source expression can still display the wrong mathematical
relationship.

Find visible working logs, author comments, temporary figure descriptions, remaining
placeholders, and revision marks inappropriate for the requested final output.
Distinguish internal notes from real manuscript text inside a revision macro:
removing markup must preserve the intended prose. Handle draft numeric placeholders
according to the current task and project conventions.

## Check consistency and references

Apply the relevant checks in
[Writing and consistency](writing-and-consistency.md) across the requested scope:
definitions, symbols, units, repeated numbers, table emphasis, captions, and claims.

Verify both that references resolve and that their targets contain the promised
material. A valid appendix label can still point to content that no longer supports
the sentence. Compare figure captions with the actual panels, objects, and labels.
Check that the main paper and supplement intentionally cite the same or different
versions of a source.

If a bibliographic identity or factual attribution is uncertain, consult the actual
publication or authoritative source. Do not infer support merely because a citation
compiles.

## Inspect the page layout

At normal reading size, inspect the affected or requested pages for clipped or
overlapping text, unreadable tables, misplaced captions, excessive gaps, isolated
headings, and awkward figure wrapping or page breaks. Check that figures are present,
sharp enough, and sized appropriately beside their captions and surrounding prose.

Keep fixes proportional. A caption change may need a local layout adjustment;
it does not warrant redesigning unrelated figures or changing the whole template.

## Report findings so they can be acted on

Distinguish:

- **Definite errors:** the visible text, arithmetic, reference, or layout is clearly wrong.
- **Questions requiring confirmation:** competing scientific definitions, implementation
  claims, or missing evidence prevent a reliable correction.
- **Optional improvements:** wording or presentation could improve but is not an error.

Give the location, reason, and a concise proposed correction. Use PDF pages and source
locations where available. Do not turn a review into an obligation to maintain a
separate issue-management system. If a continuing list is useful, update one short
existing list so resolved items do not remain marked as pending.

A request for review does not automatically authorize source edits. A request to
fix the identified issues does; avoid asking again about already-authorized fixes.

## Deliver the requested PDFs

Use the project's build process in
[Collaboration and build](collaboration-and-build.md). Deliver the requested main,
supplementary, or combined outputs from the checked version, with clear names.

For a combined paper and supplement, verify page order, appendix identification,
bibliography handling, figure/table numbering, and cross-references. Follow the
supplied or currently verified venue requirements rather than assuming a universal
submission format.

Separate successful compilation and export from unresolved content questions.
Report the delivered paths, checks completed, and any remaining material issue,
along with relevant commit and synchronization status. Do not label unperformed
checks as passed or imply that exporting a PDF resolves an open scientific question.
